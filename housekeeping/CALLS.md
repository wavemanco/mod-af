# Claude's calls in Phase 3, and the choices they replaced

The Phase 3 plan's first seven calls, kept in one place so that any of them can be changed back later: if the
harness changes shape, for example, or the consent posture changes. The owner asked Claude to make the phase's calls
itself ("For phase 3, use Google's EGM framework (the skills are already installed but I don't want a stop and ask
approach. deal with things autonomously)", 2026-11-13 UTC). After reading them the owner answered, on 2026-11-13: "the
calls you made are fine by me for now."

Quotation marks hold exact text. Each quote says whose it is: the owner's words, typos included, or the design's, a
backlog row's, or an option Claude asked with. Everything else is Claude's. Where the earlier choice was Claude's
proposal that the owner approved with the design (the owner's "Approve it", 2026-11-03, draft 2), the row says so. All 17 calls, with every option rejected, are in the plan's table
([`plans/2026-11-13-phase-3.md`](plans/2026-11-13-phase-3.md)). DESIGN section 10 sums them up.
