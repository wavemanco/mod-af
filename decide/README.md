# decide

A decision brief for any choice — so you pick well instead of being handed a verdict with no alternatives, or a menu with no guidance.

`/decide <the decision>` produces:

- **The decision** in one sentence, and whether it's reversible or a one-way door.
- **Options** — two to five real ones. Each explained *user/product-first* (what it means for the people using the thing), then the technical shape only where it changes the call — with pros, cons, **reversibility**, **cost-if-wrong**, and rough effort.
- **A committed recommendation** with the why, tied to your goals — not fence-sitting. If the call is genuinely yours to make, it says so and gives you the one question that settles it.
- **What would change it** — the facts to watch.
- **A durable decision record** — offered after, so the choice and its reasoning don't live only in chat.

It's written to be followed by a **non-technical / product** reader, not just an engineer.

## Install

```
/plugin install decide --marketplace wavemanco/mod-af
```
